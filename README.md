# Plowline

Calendar, clients, payments and insights for service businesses. The demo workspace uses a snow plowing company's data (all fake, generated in `src/lib/demo.ts`).

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` deploy to GitHub Pages through `.github/workflows/deploy.yml`.
In the repo, go to Settings → Pages → Source and choose **GitHub Actions**.
Site URL: `https://<user>.github.io/<repo>/`
